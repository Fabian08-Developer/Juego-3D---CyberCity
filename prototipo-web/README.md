# Prototipo web (Three.js) — referencia

Primera versión de CyberCity hecha con Three.js + TypeScript + Vite. El proyecto principal ahora es Godot 4
(ver el README de la raíz); este prototipo se conserva como referencia.

```bash
cd prototipo-web
npm install
npm run dev   # http://localhost:5173  (?nolock para jugar sin Pointer Lock)
```
